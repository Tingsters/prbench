# Notes for agents working on prbench

- Bun + TypeScript. Run `bun test` and `bun run typecheck` before finishing a change.
- Systems under test must never see a case's fact sheet. Don't add it to `RunContext` or copy it into sandboxes.
- Metrics read `PRArtifact`s only, never tool-specific files, so prbench stays independent of any particular tool.
- `cases/example-greet-default` is generated by `bun run example`. Regenerate it rather than editing it by hand; its commit SHAs are fixed.
- Don't commit real session logs without consent and redaction (see `docs/cases.md`).
